## 背景与动机

生电（生存+红石技术）玩家在长期存档里，最头疼的就是很多物品"一次性"——用掉就再也拿不到了，或者根本没法在不破坏世界的前提下批量获得。于是想做一份数据包，把原版缺的再生配方补上。

项目参考了 SunnySlopes 的早期配方数据包，在其逻辑上做了优化，并针对"什么才算可再生""会不会破坏平衡"两个问题，定下了一套自己的标准。

## 设计准则

### 1. 可再生的"防杠"标准

> 只要存在主流且专门的获得方式（包括利用 bug 的刷沙机、非随机的流浪商人等），就视为可再生；**随机性方式不算**（如末影龙的随机掉落）。

这个定义直接决定了一批配方的取舍——所以**粘土和珊瑚块的合成被保留**（它们有主流再生方式），而钻石、下界残骸这类争议性物品一开始就不考虑加，但**矿石合成**不受影响。

### 2. 造价对等

作者本人也是生电玩家，所以尽力让"原料获得性"与"产物价值"对等，以尽量减小对游戏难度的冲击。代价是某些物品（如鞘翅）造价依然很高——这类高价值物不能靠廉价配方批量产，否则会破坏长线目标。

### 3. NBT 与附魔的现实约束

数据包配方有个硬限制：**合成出的物品无法保留 NBT 数据**。最典型的就是鞘翅——合成后会**消除附魔**，README 里专门标注了这一点。

## 配方归类

数据包把配方按用途拆成几类，便于玩家理解：

- **便利（conveniences）**：切石机切木头、骨块/面包/纸/潜影盒/投掷器无序合成、灵魂沙→灵魂土等生活向便利。
- **原版优化（vanilla optimization）**：让深板岩圆石、黑石替代圆石进入投掷器/发射器/侦测器/活塞/拉杆配方，解决"废石没地方用"。
- **再生（renewables）**：远古残骸、珊瑚块、黏土、蜘蛛网、马铠、龙首、鞘翅、海洋之心、海绵、孢子花、凝灰岩、唱片等一大批再生配方。
- **原矿合成（ore crafting）**：主世界矿石 + 深板岩变种，用粗矿/粗矿块无序合成，可吃时运。
- **通用染色（universal dyeing）**：直接用染料原材料染色、重新染色、水桶去色。

## 原矿合成与期望值

原矿合成是重头：把"矿石直接对应其产物"变成可逆的资源转换。配合时运三，各矿期望值：

| 矿石 | 时运三期望 |
| --- | --- |
| 煤 / 铁 / 金 / 钻石 / 石英矿 | 2.2 |
| 红石矿 | 6 |
| 铜矿 | 7.7（配方含粗铜块，因期望过高） |
| 青金石矿 | 14.3 |
| 下界金矿 | 8.8 金粒 |

这里头最反直觉的是青金石——期望值高到离谱，作者在 README 里都忍不住吐槽"为什么你期望这么高啊"。

## 通用染色的坑

- 染色可直接用染料原材料，但**需要烧炼的原料（如仙人掌）不算**。
- 已染色物品能直接重染。
- 最坑的一条：**潜影盒染色/去色前一定要把里面的东西拿出来**，否则产物会丢失 NBT 中的盒内物品。
